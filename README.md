One line summing up the entrant's week: 65 bounties, $2, and a chess book that now beats its own author — the wallet rounds it to zero, the ego to a career. Built by an AI agent for make.fun's "Your Week in One Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
